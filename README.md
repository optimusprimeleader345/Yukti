# 📖 Overview

Yukti is a state-of-the-art AI Engineering Intelligence Operating System built for modern engineering teams. It solves the frustration of drowning in complexity, technical debt, and invisible architecture risks.

Instead of functioning as a traditional code assistant, Yukti combines repository intelligence, AI reasoning, architecture visualization, engineering insights, and intelligent recommendations into a single, beautifully designed workspace.

Our AI doesn't just scan code—it understands intent, maps relationships, and surfaces insights that human developers would take weeks to discover. Built with the aesthetic precision of Claude Desktop and Cursor, Yukti provides a calm, progressive, and ultra-premium workspace for your codebase.

---

# ✨ Core Features

## 🤖 AI Repository Intelligence
- Instantly map complex repository structures, data flows, and circular dependencies.
- Codebase summarization and Dependency analysis.

## 💬 AI Workspace
- A distraction-free environment that reveals complexity only when summoned.
- AI-powered engineering assistant with repository-aware responses.

## 🏗 Architecture Intelligence
- System architecture analysis & module relationship visualization.
- Dependency mapping and project structure understanding.

## 🔍 Deep Security & Technical Debt Analysis
- Catch exposed API keys, vulnerabilities, and misconfigurations before they hit staging.
- Identify deprecated patterns and generate automated refactoring roadmaps.

## 🚀 Seamless Integrations
- Connects directly to GitHub via OAuth for instant repository indexing.
- Alternatively, upload `.zip` projects or documentation (`.md`, `.pdf`) directly.

# 🚀 Getting Started

### Prerequisites
Make sure you have Node.js (v18+) installed.

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/optimusprimeleader345/Yukti.git
   ```
2. Navigate to the project directory
   ```bash
   cd yukti
   ```
3. Install dependencies
   ```bash
   npm install
   ```
4. Start the development server
   ```bash
   npm run dev
   ```
5. Open `http://localhost:5173` in your browser.

# 🎨 Architecture & Design Philosophy

Yukti enforces a strict **Progressive Disclosure** UI paradigm:
1. **The Ethereal Landing Page:** Glassmorphism, 3D animations, and dynamic gradients capture attention.
2. **The Precision Workspace:** Once authenticated, the app shifts into a minimalist, high-utility canvas featuring huge whitespace, clean typography, and 1px borders—inspired by Linear and Claude Desktop.
