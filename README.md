# 📖 Overview

Yukti is an AI-powered Engineering Intelligence Platform designed to help developers and engineering teams understand complex software systems.

Instead of functioning as a traditional code assistant, Yukti combines repository intelligence, AI reasoning, architecture visualization, engineering insights, and intelligent recommendations into a single workspace.

The platform aims to reduce onboarding time, improve code quality, and assist developers in making better technical decisions.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/optimusprimeleader345/Yukti.git
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```
